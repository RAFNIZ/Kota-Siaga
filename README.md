# Kota Siaga — Arunika Metropolitan

**Building a Safer, More Prepared, and Inclusive City Through Interactive Simulation.**

Kota Siaga — Arunika Metropolitan is a semi-3D educational city simulation game developed using Godot Engine 4.7.2. The game focuses on disaster mitigation, community preparedness, emergency response, and inclusive urban development through interactive gameplay.

Players explore a simulated urban environment, experience disaster scenarios, interact with citizens, and participate in inspection and repair activities to help create a safer and more resilient city.

## Project Information

| Property | Details |

| Platforms | Windows and macOS |
| Programming Language | GDScript |

## Key Features

- **Disaster Mitigation Simulation** — Experience educational scenarios focused on disaster preparedness and urban safety.
- **Dynamic Disaster Scenarios** — Encounter extreme rainfall, flooding, and tornado events.
- **Character and NPC Interaction** — Explore the city and interact with characters and non-player citizens.
- **Inspection and Repair Activities** — Identify environmental problems and participate in urban improvement activities.
- **Traffic and Vehicle Systems** — Explore an urban environment featuring vehicles, road networks, and traffic light systems.
- **Integrated Audio System** — Experience background music, environmental ambience, and gameplay sound effects.
- **Interactive User Interface** — Access gameplay information, missions, and city status through the in-game interface.

**Installation**

**Windows**
1. Download `Kota-Siaga-Windows.zip`.
2. Extract the ZIP archive.
3. Keep `Kota Siaga.exe` and `Kota Siaga.pck` in the same folder.
4. Run `Kota Siaga.exe`.

**macOS**
1. Download `Kota-Siaga-macOS.zip`.
2. Extract the ZIP archive.
3. Open the extracted application.
4. If macOS displays a security warning, follow the appropriate macOS security settings to open the application.

For the latest version and release notes, visit the [GitHub Releases](https://github.com/RAFNIZ/Kota-Siaga/releases) page.

## Running the Source Project

To open and run the project from source, you need:

- Godot Engine 4.7.2
- Windows or macOS

**Steps**

1. Clone this repository:

   ```bash
   git clone https://github.com/RAFNIZ/Kota-Siaga.git
   ```

2. Open Godot Project Manager.
3. Select **Import**.
4. Locate the downloaded repository folder.
5. Select `project.godot`.
6. Open the project and wait for the initial asset import.
7. Press **F5** or select **Run Project** to launch the game.
